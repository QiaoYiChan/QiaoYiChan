## 🔍 &nbsp;Behind the Code

> *"A working feature is the starting point, not the entire solution."*

I like looking beyond whether something works, to understand **why it was built that way** and **how the pieces fit together**.

I'm currently studying IT with a focus on **cloud automation**, and along the way I've been exploring software development, system design, and the decisions that connect them.

<details>
<summary><b>✨ A little more about how I approach things</b></summary>
<br>

| | Principle |
| :-: | :-- |
| ☝️ | **Understand the problem first** before reaching for a solution |
| ✌️ | **Make sensible trade-offs** and be able to explain them |
| 👌 | **Learn from what doesn't work** the first time |

Outside of coding, I'm interested in how technology fits into real-world processes and how it affects our daily lives.

</details>
